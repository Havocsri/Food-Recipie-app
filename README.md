## PROJECT FOOD RECIPE 
  
  # Recipe Explorer

Recipe Explorer is a modern food recipe landing page built with React and Vite. It showcases a clean UI with a navigation bar, search section, and a featured food image slider.

## Features

- Responsive layout
- Modern hero section
- Recipe-themed landing page
- Search bar and category navigation
- Food image carousel
- Clean styling using Tailwind CSS


## Pages and Navigation

- The Home page has a welcome section and food categories.
- The Categories page shows food categories from TheMealDB.
- Use the navigation bar to move between Home and Categories.
- React Router handles page navigation.
